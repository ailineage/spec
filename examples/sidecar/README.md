# Sidecar example

- `hello.go` — a Go file with the optional header comment `// ailineage: urn:sha256:…` on its first line ([REQ-0221]).
- `hello.go.lineage.json` — its manifest, identical to [fixture 03](../../fixtures/valid/03-code-created-claude-code-sidecar.json).

The header line is removed before hashing, so `artifact.id` equals the hash of `fixtures/data/hello.go` (the same file without the header):

```sh
tail -n +2 hello.go | shasum -a 256
# equals the hex part of artifact.id in hello.go.lineage.json
```

Both files are generated by `make fixtures-regen`.
