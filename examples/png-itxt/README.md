# PNG iTXt example

`image-64.ailineage.png` is [`fixtures/data/image-64.png`](../../fixtures/data/image-64.png) with the manifest of [fixture 01](../../fixtures/valid/01-image-created-comfyui.json) embedded as an `iTXt` chunk ([REQ-0210]–[REQ-0212]):

| iTXt field | Value |
| --- | --- |
| Keyword | `ailineage` |
| Compression flag / method | `0` / `0` |
| Language tag | empty |
| Translated keyword | empty |
| Text | UTF-8 manifest JSON (here in JCS form) |

The chunk is placed immediately before `IEND`. Removing it yields the original file byte for byte, so `artifact.id` is the SHA-256 of `fixtures/data/image-64.png`.

[`hexdump.txt`](hexdump.txt) shows the beginning and end of the chunk. Generated by `make fixtures-regen`.

To inspect with standard tools:

```sh
python3 -c "import sys,struct; b=open(sys.argv[1],'rb').read(); i=8
while i < len(b):
    n,=struct.unpack('>I',b[i:i+4]); t=b[i+4:i+8]; print(i, t.decode(), n); i+=12+n" image-64.ailineage.png
```
